# 全新服务器发布：不迁移本机业务数据

本机的任务、聊天、个人 Key、员工自定义配置、成片和数据库应继续留在本机。
服务器发布程序源码、正式界面素材、默认技能目录和经校验的公共技能安装包。
新用户自行注册或通过平台登录，再配置自己的 Key 和工作空间。

## 生成干净源码包

在项目根目录运行（输出文件必须不存在，且位于项目目录之外）：

```sh
python3 scripts/export-clean-source.py ../releases/wishtaday-clean-source.tar.gz
```

脚本读取 Git 跟踪的工作区文件，并加入本说明和导出脚本；不会递归复制本机目录。
唯一额外加入的是技能目录中声明已下载、且 SHA-256 校验一致的公共技能 ZIP。
这些是技能库安装功能需要的产品资源，不是用户的技能绑定或任务数据。
包中附有 RELEASE-CONTENTS.json，供核对文件清单和校验值。
脚本拒绝私有路径、密钥文件、数据库备份、符号链接以及覆盖已有输出。
新增未跟踪的源码需要先纳入版本管理，才会进入以后的包。

不要上传整个本机项目目录，不要上传 .local、.env、outputs、RESTORE-KEY.json，
不要恢复本机数据库或媒体备份，不要复制本机 operations-config.key。
Docker 的排除规则还会排除本地状态、开发缓存和设计原稿；正式角色素材保留在
apps/web/public 中。源码包保留受版本管理的设计文件，以支持现有角色一致性测试。

## 服务器首次安装

1. 使用全新的、独立的数据库和媒体存储；复用旧卷或旧数据库不会自动变成空白。
2. 按部署要求新建服务器密钥、数据库账号及连接配置，不复用开发机配置文件。
3. 只执行结构迁移及正式部署步骤，不运行本地演示初始化或恢复脚本。
4. 通过平台登录创建工作空间，确认任务、聊天和个人 Key 初始为空。
5. 用户自行保存个人 Key，验证隔离后再开放使用。

此包是源码交付包，并非已经启动成功的云端安装。数据库、缓存、视频服务及平台身份
认证仍需在服务器分别接通。当前主 Docker 镜像不打包 AiToEarn 独立服务。
GitHub 导入不会携带本机忽略的技能 ZIP；如走 GitHub 发布，需要另行提供这些已校验的
公共技能包，或在构建流程下载并校验，否则部分内置技能会提示安装包缺失。

清理缓存不会修复云平台的 CPU／内存调度不足；这两项要分别处理。
